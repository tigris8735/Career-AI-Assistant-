## 🎯 Введение

**AI Career Scout** — интеллектуальная система на базе DeepSeek API 3.2, которая помогает соискателям находить действительно качественные вакансии на HH.ru, исключая мусор и "затычки".

### 🌟 Основные возможности

#### 🧠 Умная верификация навыков:
- **Адаптивное тестирование** на основе резюме
- **Оценка реального уровня** (Junior/Middle/Senior)
- **Проверка hard/soft skills** через DeepSeek API
- **Персонализированные рекомендации** по развитию

#### 🔍 Интеллектуальный поиск вакансий:
- **AI-фильтрация** проплаченных и фейковых вакансий
- **Поиск только качественных** предложений
- **Семантический анализ** требований
- **Ранжирование по релевантности**

#### 🤝 Интеграция с системой образования:
- **Специальные программы** для студентов министерств
- **Массовая регистрация** через учебные заведения
- **Отслеживание трудоустройства** выпускников
- **Карьерные траектории** от обучения до работы

## 🚀 Быстрый старт

### Требования к окружению:
- Docker 20.10+ и Docker Compose 2.20+
- 8GB RAM (рекомендуется 16GB для ML)
- 20GB свободного места
- Python 3.12+ (для разработки)

### Локальный запуск за 5 минут:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-org/ai-career-scout.git
cd ai-career-scout

# 2. Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env, добавьте API ключи DeepSeek и HH.ru

# 3. Запустите систему
docker-compose up -d

# 4. Проверьте статус
docker-compose ps

# 5. Откройте в браузере
# Веб-приложение: http://localhost:3000
# API документация: http://localhost:8000/docs
# Мониторинг: http://localhost:9090 (Prometheus)
```

### Быстрое тестирование API:


### Технологический стек:

#### Backend (Python):
- **Фреймворк:** FastAPI 0.104+ (асинхронный)
- **AI движок:** DeepSeek API 3.2 + кастомизация
- **Базы данных:** PostgreSQL 16, Redis 7.2, Qdrant 1.7
- **Очереди:** Celery + RabbitMQ 4.0
- **Парсинг:** BeautifulSoup4, Scrapy, Selenium
- **Файлы:** MinIO/S3 совместимое хранилище

#### Frontend (Vue 3):
- **Фреймворк:** Vue 3 + Composition API + TypeScript
- **UI библиотека:** Naive UI + TailwindCSS
- **State management:** Pinia 2
- **Чарты:** Apache ECharts
- **Мобильное:** PWA с Capacitor

#### DevOps:
- **Контейнеризация:** Docker + Kubernetes
- **CI/CD:** GitLab CI/CD + ArgoCD
- **Мониторинг:** Prometheus + Grafana + Loki
- **Логирование:** ELK Stack
- **Хостинг:** Yandex Cloud Managed Kubernetes

## 💻 Разработка

### Установка для разработки:

```bash
# 1. Клонирование и настройка
git clone https://github.com/your-org/ai-career-scout.git
cd ai-career-scout

# 2. Настройка Python окружения
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Установка зависимостей
pip install -r requirements/dev.txt
pip install -r requirements/ml.txt

# 4. Настройка переменных окружения
cp .env.example .env.development
# Отредактируйте файл, добавьте API ключи

# 5. Инициализация базы данных
alembic upgrade head

# 6. Запуск сервисов
docker-compose -f docker-compose.dev.yml up -d

# 7. Запуск бэкенда
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 8. Запуск фронтенда
cd frontend
npm install
npm run dev
```

### Ключевые метрики:

#### Для пользователей:
- **Время тестирования:** Среднее время прохождения теста

- **Удовлетворенность:** NPS и отзывы
- **Трудоустройство:** % нашедших работу через систему

#### Для системы:
- **Доступность:** Uptime > 99.9%

- **Ошибки:** Error rate < 0.1%

#### Для партнеров:
- **Трудоустройство выпускников:** +30% к среднему показателю
- **Время поиска:** Сокращение с 3 месяцев до 1 месяца
