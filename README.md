## 🎯 Введение

**AI Career Scout** — интеллектуальная система на базе DeepSeek-r1t2-chimera, которая помогает соискателям находить более подходящие вакансии на HH.ru, путем исключения недостоверных данных.

### 🌟 Основные возможности

#### 🧠 Умная верификация навыков:
- **Адаптивное тестирование** на основе резюме
- **Оценка реального уровня** (Junior/Middle/Senior)
- **Проверка hard/soft skills** через DeepSeek API
- **Персонализированные рекомендации** по развитию

#### 🔍 Интеллектуальный поиск вакансий:
- **AI-фильтрация** проплаченных и фейковых вакансий
- **Поиск только подходящих** предложений
- **Семантический анализ** требований
- **Ранжирование по релевантности**


## 💎 Ценность продукта

### Для соискателей:
**"Получайте только релевантные предложения, соответствующие вашему реальному уровню"**

- **Экономия времени:** Не тратьте время на неподходящие вакансии вакансии

#### Для пользователей:
