# Бизнес-требования проекта: AI Career Scout

## 📊 Бизнес-идея

**Название:** AI Career Scout - Умный скаут карьеры на основе DeepSeek

**Суть продукта:** Интеллектуальный агент на базе DeepSeek API 3.2, который:
1. **Верифицирует навыки** соискателя через адаптивное тестирование
2. **Фильтрует качественные вакансии** на HH.ru, исключая "затычки" для слежения за рынком
3. **Персонализирует подбор** на основе реального уровня знаний и резюме
4. **Упрощает отклик** - пользователь выбирает из подготовленного списка

**Ценность:**
- **Для соискателей:** "Получайте только релевантные предложения, соответствующие вашему реальному уровню"
- **Для рынка труда:** "Снижение шума, повышение качества рекрутинга"

**Целевая аудитория:**

### Основные сегменты:
1. **IT-специалисты** (Junior/Middle/Senior) - разработчики, DevOps, аналитики
2. **Цифровые профессионалы** - маркетологи, дизайнеры, продуктовые менеджеры
3. **Ученики федерального министерства обучения**:
   - Студенты последних курсов
   - Участники государственных образовательных программ
   - Выпускники федеральных учебных заведений
4. **Ученики московского министерства обучения**:
   - Учащиеся московских вузов и колледжей
   - Участники городских программ переподготовки
   - Карьерные мигранты внутри столицы

### Специфика для учеников министерств:
- **Интеграция с образовательными программами**
- **Приоритетный доступ к стажировкам и junior-позициям**
- **Специальные условия подписки через институты**
- **Поддержка карьерного роста от обучения до трудоустройства**
