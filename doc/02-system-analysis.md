# Системный анализ и технические требования

## 🎯 Общее описание системы

AI HR Assistant - это веб-приложение с микросервисной архитектурой, которое:
1. **Принимает резюме пользователя** в форматах PDF/DOCX
2. **Анализирует содержимое** с использованием LLM
3. **Сопоставляет с вакансиями** на HH.ru
4. **Генерирует адаптированные резюме** под конкретные вакансии
5. **Автоматизирует отклики** через "умного клиента"
6. **Предоставляет аналитику** и рекомендации по развитию

## 🔧 Функциональные требования

### Модуль 1: Загрузка и обработка резюме
**FR-1.1:** Система должна принимать файлы форматов PDF, DOCX, DOC
- Максимальный размер: 10MB
- Поддержка русских и английских языков
- Валидация структуры документа

**FR-1.2:** Извлечение структурированных данных
- Контактная информация (имя, email, телефон)
- Опыт работы (компании, должности, периоды, обязанности)
- Образование (учреждения, специальности, годы)
- Навыки (технические, soft skills)
- Достижения и проекты

### Модуль 2: Анализ вакансий HH.ru
**FR-2.1:** Получение вакансий с HH.ru
- Поиск по ключевым словам и фильтрам
- Ограничение: до 1000 вакансий в сутки на пользователя
- Кэширование результатов на 24 часа

**FR-2.2:** Анализ требований вакансий
- Извлечение обязательных и желательных требований
- Анализ уровня зарплаты
- Оценка уровня позиции (junior/middle/senior)
- Ключевые слова и технологии

### Модуль 4: Автоматизация откликов
**FR-5.1:** "Умный клиент" для HH.ru
- Имитация человеческого поведения
- Рандомизация времени откликов
- Обработка капчи (при необходимости)
- Логирование всех действий

**FR-5.2:** Управление кампаниями
- Настройка правил откликов
- Лимиты по дням/неделям
- Черный список компаний
- Авто-пауза при достижении лимитов

### Модуль 5: Чат-поддержка и подготовка
**FR-6.1:** AI-чат для подготовки
- Ответы на вопросы по вакансиям
- Симуляция собеседований
- Рекомендации по развитию навыков
- Генерация вопросов работодателю

**FR-6.2:** План развития
- Индивидуальная roadmap на 30/60/90 дней
- Рекомендации курсов и материалов
- Тренировочные задания
- Прогресс трекинг
