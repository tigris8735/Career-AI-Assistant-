
# **ТЕХНИЧЕСКОЕ ЗАДАНИЕ**
## **Проект: AI Career Scout — Умный скаут карьеры**
**Версия:** 2.3.0  
**Дата:** 12.12.2025  
**Статус:** Утверждено


## **1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА**

### **1.1. Назначение системы**
AI Career Scout — интеллектуальная система на базе DeepSeek API, предназначенная для автоматизированного поиска работы и подбора персонала. Система выполняет верификацию навыков соискателей через адаптивное тестирование и осуществляет интеллектуальный поиск вакансий на HH.ru с фильтрацией нерелевантных предложений.

### **1.2. Цели проекта**
#### **Бизнес-цели:**
- Запуск MVP за 2 месяца
- Привлечение 1000 пользователей в первые 3 месяца
- Достижение точности фильтрации вакансий > 85%
- Монетизация через подписки (Standard/Premium/Корпоративный)

#### **Технические цели:**
- Создание масштабируемой микросервисной архитектуры
- Интеграция с DeepSeek API для анализа навыков
- Реализация парсинга и фильтрации HH.ru
- Обеспечение uptime 99.9%

### **1.3. Целевая аудитория**
**Основные пользователи:**
1. **IT-специалисты** (разработчики, DevOps, аналитики)
2. **Студенты вузов/колледжей**
3. **Администраторы учебных заведений**
4. **Пассивные соискатели** (открытые к предложениям)

## **2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ**

### **2.1. Модуль аутентификации и профилей (FR-01)**
#### **FR-01.1: Регистрация пользователей**
- Регистрация по email/паролю
- Валидация студенческих email для особого тарифа
- Подтверждение email через ссылку
- Выбор тарифа при регистрации (Free/Standard/Premium)

#### **FR-01.2: Управление профилем**
- Заполнение персональных данных (ФИО, контакты, локация)
- Указание опыта работы и специализации
- Настройка предпочтений поиска (зарплата, тип занятости, удаленка)
- Управление подпиской и тарифами

### **2.2. Модуль работы с резюме (FR-02)**
#### **FR-02.1: Загрузка и анализ резюме**
- Поддержка форматов: PDF, DOCX, TXT (до 10 МБ)
- Автоматическое извлечение структурированных данных:
  - Контактная информация
  - Опыт работы (компании, должности, периоды)
  - Технические навыки и стек технологий
  - Образование и сертификаты
- Ручная корректировка извлеченных данных
- Хранение истории версий резюме

#### **FR-02.2: Анализ и оценка резюме**
- Выявление пробелов в знаниях
- Сравнение с рыночными требованиями
- Формирование рекомендаций по улучшению резюме

### **2.3. Модуль тестирования компетенций (FR-03)**
#### **FR-03.1: Адаптивное тестирование**
- Генерация вопросов на основе анализа резюме
- Динамическое изменение сложности вопросов:
  - Правильный ответ → повышение сложности
  - Неправильный ответ → понижение сложности
- Тестирование по 20+ технологическим стекам
- Ограничение времени на ответ (зависит от сложности)

#### **FR-03.2: Оценка уровня компетенций**
- Автоматическое определение уровня: Junior/Middle/Senior
- Оценка hard skills (технические знания)
- Оценка soft skills (коммуникация, решение задач)
- Формирование детального отчета о сильных/слабых сторонах

#### **FR-03.3: Расширенное тестирование (Premium)**
- Практические задачи с кодом
- Системное проектирование и архитектурные кейсы
- Психометрическое тестирование
- Консультация с карьерным консультантом (опционально)

### **2.4. Модуль парсинга HH.ru (FR-04)**
#### **FR-04.1: Сбор данных с HH.ru**
- Парсинг веб-страниц вакансий
- Использование HH.ru API
- Обновление базы вакансий каждые 4 часа
- Обработка до 100,000 вакансий в сутки

#### **FR-04.2: AI-фильтрация вакансий**
- Исключение "вакансий-затычек"
- Выявление проплаченных/нерелевантных позиций
- Оценка качества описания вакансии
- Проверка реальности требований
- Классификация по категориям (IT, маркетинг, дизайн и т.д.)

### **2.5. Модуль сопоставления и рекомендаций (FR-05)**
#### **FR-05.1: Точное сопоставление**
- Сравнение навыков соискателя с требованиями вакансий
- Учет зарплатных ожиданий
- Учет географических предпочтений
- Анализ стека технологий

#### **FR-05.2: AI-ранжирование (Premium)**
- Многофакторное ранжирование:
  - Соответствие навыков (40%)
  - Карьерный рост (25%)
  - Культурное соответствие (20%)
  - Зарплатные ожидания (15%)
- Группировка вакансий по категориям:
  - Идеальное совпадение (90-100%)
  - Отличный вариант (70-89%)
  - Для роста (50-69%)
  - Альтернативные (30-49%)

#### **FR-05.3: Формирование рекомендаций**
- Топ-10 наиболее релевантных вакансий
- Альтернативные варианты для роста
- Стажировки для студентов
- Персональные рекомендации по развитию

### **2.6. Модуль откликов и коммуникации (FR-06)**
#### **FR-06.1: Упрощенный отклик**
- Единая форма отклика с автозаполнением

#### **FR-06.2: Трекинг откликов**

### **2.7. Модуль аналитики и отчетности (FR-07)**
#### **FR-07.1: Статистика рынка**

## **6. ИНТЕРФЕЙСЫ И ИНТЕГРАЦИИ**

### **6.1. Внешние API**
#### **DeepSeek API:**
- **Назначение:** AI анализ резюме, генерация вопросов, фильтрация вакансий
- **Endpoints:**
  - POST `/api/v1/analyze-resume` - анализ резюме
  - POST `/api/v1/generate-questions` - генерация тестовых вопросов
  - POST `/api/v1/classify-vacancy` - классификация вакансий
- **Rate limiting:** 100 запросов/минуту

#### **HH.ru API:**
- **Назначение:** Получение вакансий, отправка откликов
- **Endpoints:**
  - GET `/vacancies` - поиск вакансий
  - POST `/applications` - отправка откликов
  - GET `/vacancies/{id}` - детали вакансии
- **Авторизация:** OAuth 2.0

### **6.2. Внутренние API**
#### **Основные эндпоинты:**
```
POST   /api/v1/auth/register       - Регистрация
POST   /api/v1/auth/login          - Вход
POST   /api/v1/auth/refresh        - Обновление токена
POST   /api/v1/resumes/upload      - Загрузка резюме
GET    /api/v1/resumes/{id}        - Получение резюме
POST   /api/v1/tests/start         - Начать тестирование
POST   /api/v1/tests/{id}/answer   - Ответить на вопрос
GET    /api/v1/tests/{id}/result   - Получить результат
GET    /api/v1/vacancies/search    - Поиск вакансий
POST   /api/v1/vacancies/{id}/apply- Откликнуться на вакансию
GET    /api/v1/analytics/market    - Рыночная статистика
```

## **7. МОДЕЛИ ДАННЫХ**

### **7.1. Основные сущности**
#### **User (Пользователь):**
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(255),
    phone VARCHAR(20),
    location VARCHAR(100),
    experience_years INTEGER,
    specialization VARCHAR(100),
    subscription_type VARCHAR(20),
    subscription_expires_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### **Resume (Резюме):**
```sql
CREATE TABLE resumes (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    file_path VARCHAR(500),
    raw_text TEXT,
    parsed_data JSONB,
    skills JSONB,
    experience JSONB,
    education JSONB,
    analysis_result JSONB,
    created_at TIMESTAMP DEFAULT NOW(),
    is_active BOOLEAN DEFAULT TRUE
);
```

#### **Test Result (Результат теста):**
```sql
CREATE TABLE test_results (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    level VARCHAR(20), -- Junior/Middle/Senior
    score INTEGER,
    skills_assessment JSONB,
    recommendations JSONB,
    completed_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### **Vacancy (Вакансия):**
```sql
CREATE TABLE vacancies (
    id UUID PRIMARY KEY,
    external_id VARCHAR(100), -- ID из HH.ru
    title VARCHAR(500) NOT NULL,
    company VARCHAR(255),
    salary_from INTEGER,
    salary_to INTEGER,
    currency VARCHAR(10),
    location VARCHAR(255),
    remote BOOLEAN DEFAULT FALSE,
    description TEXT,
    requirements TEXT,
    skills_required JSONB,
    ai_quality_score DECIMAL(3,2),
    relevance_score DECIMAL(3,2),
    parsed_at TIMESTAMP,
    expires_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);
```
