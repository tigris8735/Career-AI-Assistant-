# Системный анализ и технические требования: AI Career Scout

## 🎯 Общее описание системы

AI Career Scout - это интеллектуальная система на базе DeepSeek API, состоящая из трех основных модулей:

### 1. Модуль верификации компетенций:
- **Адаптивное тестирование** на основе резюме
- **Оценка hard skills** (технические знания)
- **Оценка soft skills** (коммуникация, решение задач)
- **Определение реального уровня** (Junior/Middle/Senior)

### 2. Модуль парсинга и фильтрации HH.ru:
- **Сбор вакансий** через API и парсинг
- **AI-классификация** качества вакансий
- **Исключение "нерелевантных"** и проплаченных позиций
- **Ранжирование** по релевантности

### 3. Модуль персонализации и отклика:
- **Сопоставление** навыков и требований
- **Формирование списка** оптимальных вакансий
- **Упрощенный интерфейс** выбора и отклика
- **Трекинг статусов** откликов

## 🔧 Функциональные требования

### Модуль 1: Профилирование и тестирование
**FR-1.1:** Умный анализ резюме
- Загрузка PDF/DOCX/TXT резюме
- Извлечение структурированных данных
- Выявление пробелов в знаниях

**FR-1.2:** Адаптивное тестирование
- Генерация вопросов на основе резюме
- Динамическая сложность вопросов
- Оценка практических навыков
- Тестирование на 20+ языках программирования

**FR-1.3:** Определение уровня
- Автоматическая классификация Junior/Middle/Senior
- Сравнение с рыночными стандартами
- Рекомендации по развитию

### Модуль 2: Парсинг HH.ru
**FR-2.1:** Сбор данных
- Парсинг веб-страниц для расширенных данных
- Обновление базы каждые 4 часа
- Обработка до 100 000 вакансий/день

**FR-2.2:** AI-фильтрация
- Исключение вакансий-затычек
- Выявление проплаченных позиций
- Оценка качества описания
- Проверка реальности требований

**FR-2.3:** Классификация
- Разделение по категориям (IT, маркетинг, дизайн)
- Определение уровня сложности
- Выявление спец. условий (удаленка, релокация)

### Модуль 3: Персонализация
**FR-3.1:** Точное сопоставление
- Сравнение навыков соискателя и требований
- Учет уровня зарплатных ожиданий
- Учет географических предпочтений
- Анализ стека технологий

**FR-3.2:** Формирование списка
- Топ-10 наиболее релевантных вакансий
- Альтернативные варианты
- Вакансии для роста
- Стажировки для студентов

**FR-3.3:** Упрощенный отклик
- Единая форма для всех вакансий
- Автозаполнение данных из профиля
- Отслеживание статусов
- Уведомления о новых подходящих вакансиях

### Модуль 4: Интеграция с министерствами
**FR-4.1:** Для федерального министерства:
- API для массовой регистрации студентов
- Отчеты по трудоустройству по регионам
- Интеграция с государственными порталами
- Аналитика востребованности профессий

**FR-4.2:** Для московского министерства:
- Специальные программы для студентов Москвы
- Приоритет к московским компаниям
- Интеграция с московскими карьерными центрами
- Программа "Карьерный старт в Москве"
