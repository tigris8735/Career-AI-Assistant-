## **🧪 User Cases: AI Career Scout**

### **User Case 1: Регистрация и создание профиля**

**ID:** UC-01  
**Название:** Регистрация нового пользователя  
**Актор:** Соискатель-IT  
**Приоритет:** Высокий  
**Триггер:** Пользователь заходит на сайт AI Career Scout

**Основной сценарий:**
1. Пользователь нажимает кнопку "Зарегистрироваться"
2. Система отображает форму регистрации
3. Пользователь вводит:
   - Email адрес
   - Пароль (минимальная сложность)
   - Подтверждение пароля
4. Пользователь указывает:
   - ФИО
   - Город проживания/поиска работы
   - Опыт работы (лет)
   - Специализация (выбор из списка IT-специальностей)
5. Пользователь выбирает тип подписки (Free/Standard/Premium)
6. Пользователь принимает условия использования и политику конфиденциальности
7. Система отправляет подтверждение на email
8. Пользователь подтверждает email по ссылке
9. Система создает профиль и перенаправляет в личный кабинет

**Альтернативные сценарии:**
- **A1:** Email уже зарегистрирован
  - Система показывает сообщение "Этот email уже используется"
  - Предлагает восстановить пароль или использовать другой email
- **A2:** Пароль недостаточно сложный
  - Система показывает требования к паролю
  - Предлагает ввести более сложный пароль
- **A3:** Пользователь не подтвердил email в течение 24 часов
  - Система отправляет напоминание
  - Через 72 часа запись удаляется

**Постусловие:** Пользователь зарегистрирован, создан профиль, доступен личный кабинет

### **User Case 2: Загрузка и анализ резюме**

**ID:** UC-02  
**Название:** Обработка резюме пользователя  
**Актор:** Соискатель-IT  
**Приоритет:** Высокий  
**Триггер:** Пользователь заходит в раздел "Мое резюме"

**Основной сценарий:**
1. Пользователь нажимает "Загрузить резюме"
2. Система открывает окно загрузки файла
3. Пользователь выбирает файл (PDF, DOCX, TXT, до 10 МБ)
4. Система проверяет формат и размер файла
5. Система загружает файл и начинает обработку
6. AI-система анализирует резюме:
   - Извлекает контактную информацию
   - Определяет опыт работы (компании, должности, периоды)
   - Выделяет технические навыки и стек технологий
   - Определяет уровень владения языками
   - Анализирует образование и сертификаты
7. Система показывает извлеченные данные для подтверждения
8. Пользователь проверяет и корректирует данные при необходимости
9. Пользователь подтверждает корректность данных
10. Система сохраняет резюме в профиле пользователя

**Альтернативные сценарии:**
- **A1:** Неподдерживаемый формат файла
  - Система показывает сообщение о поддерживаемых форматах
  - Предлагает конвертировать файл или загрузить другой
- **A2:** Файл слишком большой
  - Система показывает сообщение о максимальном размере
  - Предлагает уменьшить размер файла
- **A3:** AI не может распознать содержимое
  - Система предлагает ручной ввод данных
  - Или загрузить резюме в другом формате

**Постусловие:** Резюме проанализировано, навыки извлечены, профиль обновлен

### **User Case 3: Прохождение адаптивного тестирования**

**ID:** UC-03  
**Название:** Оценка навыков через адаптивное тестирование  
**Актор:** Соискатель-IT  
**Приоритет:** Высокий  
**Триггер:** Пользователь нажимает "Пройти тестирование" в личном кабинете

**Основной сценарий:**
1. Система анализирует резюме пользователя
2. AI определяет ключевые навыки для тестирования
3. Система генерирует первый вопрос соответствующей сложности
4. Пользователь отвечает на вопрос (время ограничено)
5. На основе ответа система определяет сложность следующего вопроса:
   - Правильный ответ → повышение сложности
   - Неправильный ответ → понижение сложности
   - Частично правильный → аналогичная сложность
6. Шаги 4-5 повторяются 20-30 раз (в зависимости от уровня)
7. Система оценивает результаты:
   - Определяет уровень (Junior/Middle/Senior)
   - Оценивает сильные и слабые стороны
   - Формирует рекомендации по развитию
8. Система показывает результаты тестирования
9. Результаты сохраняются в профиле пользователя

**Альтернативные сценарии:**
- **A1:** Пользователь прерывает тестирование
  - Система сохраняет прогресс
  - Позволяет продолжить с того же места
- **A2:** Тестирование не может определить уровень
  - Система предлагает пройти расширенное тестирование
  - Или обновить резюме и попробовать снова
- **A3:** Технические проблемы с AI
  - Система переключается на упрощенный режим тестирования
  - Уведомляет пользователя о временных ограничениях

**Постусловие:** Навыки оценены, уровень определен, рекомендации сформированы

### **User Case 4: Поиск и фильтрация вакансий**

**ID:** UC-04  
**Название:** Подбор подходящих вакансий  
**Актор:** Соискатель-IT  
**Приоритет:** Высокий  
**Триггер:** Пользователь нажимает "Найти вакансии" в личном кабинете

**Основной сценарий:**
1. Система анализирует профиль пользователя:
   - Результаты тестирования
   - Навыки из резюме
   - Опыт работы
   - Предпочтения по зарплате и локации
2. Система сканирует базу вакансий с HH.ru
3. AI фильтрует вакансии:
   - Исключает "затычки" и нерелевантные предложения
   - Проверяет качество описания вакансии
   - Анализирует реальность требований
4. Система сопоставляет навыки пользователя с требованиями вакансий
5. Формируется список из 10 наиболее подходящих вакансий
6. Для каждой вакансии показывается:
   - Процент соответствия
   - Зарплатный диапазон
   - Компания и локация
   - Ключевые требования
   - Причины рекомендации
7. Пользователь может:
   - Фильтровать по зарплате, локации, типу занятости
   - Сохранять вакансии в избранное
   - Просматривать подробную информацию

**Альтернативные сценарии:**
- **A1:** Не найдено подходящих вакансий
  - Система предлагает расширить критерии поиска
  - Или показывает вакансии "для роста" (немного выше текущего уровня)
- **A2:** Пользователь хочет изменить критерии поиска
  - Система позволяет настроить фильтры:
    - Желаемая зарплата
    - Удаленная/офисная работа
    - Конкретные технологии
    - Режим работы
- **A3:** База вакансий устарела
  - Система запускает обновление базы
  - Показывает уведомление "Идет обновление вакансий"

**Постусловие:** Пользователь получил список релевантных вакансий, готов к откликам

### **User Case 5: Упрощенный отклик на вакансии**

**ID:** UC-05  
**Название:** Отправка отклика на вакансию  
**Актор:** Соискатель-IT  
**Приоритет:** Высокий  
**Триггер:** Пользователь нажимает "Откликнуться" на вакансии

**Основной сценарий:**
1. Пользователь выбирает вакансию из списка рекомендаций
2. Нажимает кнопку "Откликнуться"
3. Система открывает форму отклика с автозаполнением:
   - ФИО из профиля
   - Контактный email
   - Телефон (если указан)
   - Ссылка на профиль в AI Career Scout
4. Система прикрепляет резюме пользователя
5. Пользователь может:
   - Добавить сопроводительное письмо (шаблон или свой текст)
   - Указать дополнительные контакты
   - Добавить ссылки на портфолио/GitHub
6. Пользователь подтверждает отправку
7. Система отправляет отклик работодателю через HH.ru API
8. Система сохраняет копию отклика
9. Пользователь видит подтверждение отправки
10. Вакансия перемещается в раздел "Отправленные отклики"

**Альтернативные сценарии:**
- **A1:** Не все обязательные поля заполнены
  - Система подсвечивает незаполненные поля
  - Не позволяет отправить отклик до заполнения
- **A2:** Работодатель указал особый способ отклика
  - Система показывает инструкции работодателя
  - Предлагает альтернативные действия (перейти на сайт компании и т.д.)
- **A3:** Ошибка при отправке через HH.ru
  - Система сохраняет отклик в черновики
  - Предлагает повторить попытку позже
  - Уведомляет администратора системы

**Постусловие:** Отклик отправлен, статус отслеживается, история сохраняется

### **User Case 6: Регистрация через учебное заведение**

**ID:** UC-06  
**Название:** Создание профиля для студента вуза/колледжа  
**Актор:** Студент вуза/колледжа  
**Приоритет:** Высокий  
**Триггер:** Пользователь переходит по специальной ссылке от учебного заведения

**Основной сценарий:**
1. Пользователь переходит по ссылке "Регистрация для студентов [Название вуза]"
2. Система определяет учебное заведение по ссылке
3. Отображается специальная форма регистрации для студентов
4. Пользователь вводит:
   - Студенческий email (например, name@university.edu)
   - Студенческий билет/номер
   - Курс и специальность
5. Система проверяет принадлежность к учебному заведению
6. При успешной проверке:
   - Активируется специальный студенческий тариф
   - Добавляется отметка "Студент [Название вуза]"
   - Открывается доступ к студенческим программам
7. Пользователь заполняет профиль (аналогично UC-01)
8. Загружает резюме (можно без опыта работы)
9. Получает доступ к специальным разделам:
   - Стажировки для студентов
   - Junior-позиции
   - Программы наставничества

**Альтернативные сценарии:**
- **A1:** Невалидный студенческий email
  - Система просит подтвердить принадлежность к вузу
  - Или предлагает стандартную регистрацию
- **A2:** Учебное заведение не является партнером
  - Система предлагает стандартную регистрацию
  - Предлагает вузу стать партнером
- **A3:** Студент уже выпустился
  - Система предлагает перейти на профиль выпускника
  - Сохраняет историю студенческих достижений

**Постусловие:** Создан студенческий профиль, открыт доступ к студенческим программам

### **User Case 7: Расширенное тестирование (Premium)**

**ID:** UC-07  
**Название:** Комплексная оценка hard и soft skills  
**Актор:** Премиум-пользователь  
**Приоритет:** Средний  
**Триггер:** Пользователь с Premium-подпиской выбирает "Расширенное тестирование"

**Основной сценарий:**
1. Пользователь начинает расширенное тестирование
2. **Часть 1: Углубленное техническое тестирование**
   - Практические задачи с кодом
   - Архитектурные кейсы
   - Системное проектирование
   - Отладка и оптимизация
3. **Часть 2: Soft skills оценка**
   - Ситуационные вопросы
   - Кейсы по коммуникации
   - Оценка лидерских качеств
   - Анализ подходов к решению проблем
4. **Часть 3: Психометрическое тестирование**
   - Определение рабочих стилей
   - Оценка мотивации
   - Анализ карьерных предпочтений
5. AI анализирует все результаты
6. Формируется подробный отчет:
   - Детальная оценка по каждому навыку
   - Сравнение с рыночными требованиями
   - Персональная дорожная карта развития
   - Рекомендации по позициям и компаниям
7. Консультация с карьерным консультантом (опционально)

**Альтернативные сценарии:**
- **A1:** Тестирование прерывается
  - Система сохраняет прогресс по частям
  - Позволяет продолжить с прерванного места
- **A2:** Противоречивые результаты
  - Система предлагает дополнительное интервью
  - Или рекомендует пересдать определенные части

**Постусловие:** Получена комплексная оценка, сформирован план развития

### **User Case 8: AI-ранжирование вакансий (Premium)**

**ID:** UC-08  
**Название:** Интеллектуальное ранжирование предложений работы  
**Актор:** Премиум-пользователь  
**Приоритет:** Средний  
**Триггер:** Премиум-пользователь запрашивает список вакансий

**Основной сценарий:**
1. Пользователь открывает раздел "Рекомендованные вакансии"
2. AI анализирует:
   - Полный профиль пользователя
   - Историю просмотров и откликов
   - Предпочтения и поведенческие паттерны
3. Система применяет многофакторное ранжирование:
   - **Соответствие навыков (40%)** - точное совпадение стека технологий
   - **Карьерный рост (25%)** - потенциал развития в компании
   - **Культурное соответствие (20%)** - совместимость с корпоративной культурой
   - **Зарплатные ожидания (15%)** - соответствие рыночному уровню
4. Для каждой вакансии рассчитывается общий score (0-100%)
5. Вакансии группируются по категориям:
   - **Идеальное совпадение** (90-100%) - прямое попадание
   - **Отличный вариант** (70-89%) - с небольшими компромиссами
   - **Для роста** (50-69%) - требуют развития навыков
   - **Альтернативные** (30-49%) - смежные специализации
6. По каждой вакансии показывается:
   - Визуализация совпадения по факторам
   - "Почему эта вакансия вам подходит"
   - "Что нужно подтянуть для идеального соответствия"
   - Статистика откликов других пользователей

**Альтернативные сценарии:**
- **A1:** Пользователь не согласен с ранжированием
  - Возможность перетаскивать вакансии
  - Система учится на предпочтениях пользователя
- **A2:** Новые вакансии появились в течение дня
  - Push-уведомление о новых высокорелевантных вакансиях
  - Автоматическое добавление в список

**Постусловие:** Пользователь видит персонализированный ранжированный список вакансий

### **User Case 9: Статистика рынка и зарплатных ожиданий**

**ID:** UC-09  
**Название:** Анализ рыночных тенденций  
**Актор:** Любой пользователь  
**Приоритет:** Низкий  
**Триггер:** Пользователь открывает раздел "Статистика рынка"

**Основной сценарий:**
1. Пользователь выбирает свою специальность и уровень
2. Система показывает дашборд статистики:
   - **Зарплатный диапазон**: медиана, 25-й и 75-й процентили
   - **Востребованность**: количество открытых вакансий
   - **Конкуренция**: количество соискателей на позицию
   - **Тренды**: динамика за последние 6-12 месяцев
3. Детализация по:
   - **Регионам**: Москва, СПб, регионы, удаленно
   - **Отраслям**: FinTech, E-commerce, Enterprise и т.д.
   - **Типам компаний**: стартапы, средний бизнес, корпорации
4. AI дает рекомендации:
   - "Ваши ожидания соответствуют рынку"
   - "Рекомендуем повысить ожидания на X%"
   - "Рассмотрите смежные специальности с большим спросом"
5. Инструменты прогнозирования:
   - Прогноз спроса на навыки через 6-12 месяцев
   - Рекомендации по обучению перспективным технологиям
   - Анализ успешных карьерных переходов

**Альтернативные сценарии:**
- **A1:** Недостаточно данных для статистики
  - Система показывает данные по смежным специальностям
  - Предлагает подписаться на обновления статистики
- **A2:** Пользователь хочет сравнить несколько специальностей
  - Возможность добавить до 3 специальностей для сравнения
  - Визуальное сравнение по ключевым метрикам

**Постусловие:** Пользователь понимает свою позицию на рынке, может скорректировать ожидания

## **🎯 Ключевые бизнес-правила**

1. **Правило доступа к вакансиям:**
   - Free: 5 вакансий в неделю
   - Standard: 20 вакансий в день
   - Premium: неограниченно + AI-ранжирование

2. **Правило определения уровня:**
   - Junior: < 2 лет опыта, базовые навыки
   - Middle: 2-5 лет опыта, самостоятельная работа
   - Senior: 5+ лет опыта, экспертиза, менторство

3. **Правило студенческого доступа:**
   - Только с подтвержденным email учебного заведения
   - Специальный доступ к стажировкам
   - Приоритет на junior-позиции

4. **Правило фильтрации вакансий:**
   - Исключаются вакансии без указания зарплаты
   - Исключаются вакансии с шаблонными описаниями
